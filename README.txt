見積もり作成アプリ　操作説明（ver.1.2）
========================================

【フォルダの見方】
普段触るのは次の4つだけです。

・見積もり一括作成.exe … アプリ本体
・README.txt … この説明書
・機種代金一覧表 … 最新の機種代金表PDFを入れる
・output … 作成した見積PDFが出る（実際の保存先は output\見積PDF）

system フォルダはアプリ内部です。中身を変更・削除しないでください。

.cursor フォルダがある場合もあります。
Cursor（開発用のAIエディタ）が参照する設定であり、見積作成の操作には使いません。
開いたり消したり変更したりする必要はありません。

【通常の一括作成】
1. 「機種代金一覧表」フォルダへ最新の機種代金表PDFを入れます。
2. 「見積もり一括作成.exe」を起動します。
3. 必要なら「作成しない機種を選ぶ」で作りたくない機種にチェックを入れて保存します。
4. 見積書へ表示する部署を選びます。
5. 「見積もり作成」を押します。

標準では事務手数料あり（税抜4,500円）の見積を作成します。
初回は対象機種の全件、2回目以降は価格変更のあった機種だけを作成します。
初回起動時は「対象機種をすべて再生成　※初回起動時は必ずチェック」にチェックが入っています。
2回目以降で差分だけ作りたい場合は、このチェックを外してください。

作成したPDFは毎回新しいフォルダにせず、output\見積PDF へ上書き／追加されます。

【中断と再開】
・作成に時間がかかるときは［中断］で止められます（いま作成中の1件が終わってから停止します）。
・［再開］で、中断した件数の続きから作成を再開できます。
・新規に「見積もり作成」を始めると、中断データは破棄されます（確認ダイアログが出ます）。

【作成しない機種】
メイン画面の「作成しない機種を選ぶ」で、作成したくない機種にチェックして保存します。
一括作成も個別見積の機種一覧も、除外していない機種だけが対象です。
チェックなし（除外なし）なら販売中の全機種が対象です。

【一括作成の追加オプション】
・事務手数料免除＋初期費用3,000円版も作成
　※ONのとき、通常版に加えて特別版も作成します
・IPS通常プランも作成（一括請求表示＋ランニングコスト表示の2パターン）
　※初期状態でチェックON。PDF数と処理時間が大幅に増える可能性があります
・IPSなしの特別対応版も作成

【部署の電話・FAX】
見積右上の住所は[REDACTED]です。
部署ごとの電話番号・FAXはヒアリング後に反映予定です（設定後は部署に合わせて切り替わります）。

【特定の機種だけ作成】
1. メイン画面の「個別見積作成」を押します。
2. 機種、販売区分、料金プランを選びます。
3. 必要なデータ容量、SB光の有無、修理保証、安心サポート、初期費用を選びます。
4. 「PDF作成」を押します。

機種欄は文字を入力して検索することもできます。
初期費用は「事務手数料あり」と「免除＋3,000円」を複数選択できます。

【データ容量のルール】
・機種代金表で「ケータイ」に分類される機種：1GBのみ
・それ以外の機種：5GB以上
・おうち割（SB光）ありの場合：5GBは作成しません（20GBと同額のため）

【SB光・おうち割】
・1GB：割引なし
・5GB：税抜500円引き（おうち割なし版のみ作成）
・20GB、50GB、無制限：税抜1,000円引き

【出力フォルダ】
次の順番で自動的に分けられます。

機種カテゴリ
　└ 機種名
　　　└ 販売区分
　　　　　└ SB光あり・なし
　　　　　　　└ 料金プラン
　　　　　　　　　└ 事務手数料あり / 初期費用3000円
　　　　　　　　　　　└ IPSサブスク / IPS一括型 / IPS一括型_月額換算 / IPSなし
　　　　　　　　　　　　　└ 安心サポートあり・なし

PDFファイル名は次のルールです。

・機種名（価格表の名称・空白なし）_パケット容量
・修理保証ありの場合は、その後ろにプラン略称が付きます

【困ったとき】
・価格表PDFが認識されない場合：PDFが「機種代金一覧表」フォルダにあるか確認してください。
・PDFが1ページに収まらない／文字が切れる場合：管理担当者へ連絡してください。
・作成件数が多いときは処理に時間がかかります。完了メッセージが出るまで待ってください。
