## 1. 概要

SoftBank 法人向けローカル完結型見積PDF一括作成ツール。

1. `機種代金一覧表` の価格表PDFを読む
2. 販売区分・プラン・容量・おうち割・IPS・安心サポート等で見積生成
3. `output/見積PDF/` に固定ルートで保存

PDFは縦向きA4・原則1ページ。

## 7. ビジネスルール (1.3.x)

- 出力固定 `output/見積PDF/`
- 除外機種 > 全件再生成
- おうち割あり + 5GB 不可
- 初期費用デフォルト: special_3000
- **Bizパッケージ＋スーパーライトはパケット50GBのみ**
- **スーパー／ハイパー**: 全販売区分でプラン名フォルダなし。**Bizパッケージ＋** と並列に **IPSあり** を置き、その下で `IPSサブスク` / `IPS一括表記` / `通常IPSランニングコスト表記` に分ける
- **Biz+・ライト**: 従来どおり料金プランフォルダを維持（ライトは機種変更では作成しない）
- EXE の会社連絡先: `%LOCALAPPDATA%\InfinityQuoteApp\data\company.json`。空の FAX は起動時に同梱マスタで補完可（開発と現場の表記差対策）
- 通常IPS: フォルダ分割 (例: ゴールド24) / ファイル名は機種_容量.pdf
- ランニングIPS: 24ヶ月以降は「－」; 36ヶ月は 25-36 / 37-48 分割
- サブスクファイル名: 機種_容量.pdf のみ
- PDF追加割引表記: **弊社特別割引**
- 現場txt: UTF-8 BOM。`?` だらけなら破損
