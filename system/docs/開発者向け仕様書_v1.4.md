## 1. 概要

SoftBank 法人向け機種代金一覧 PDF から見積PDF を一括生成する **ローカル Windows デスクトップ** アプリです。

1. `機種代金一覧表/` に価格 PDF を置く
2. GUI で一括または個別作成（プラン・販売形態・割賦回数など）
3. 固定の `output/` 配下に PDF を出力（実行ごとのタイムスタンプフォルダは作らない）

PDF は **縦 A4・1 ページ** を原則とします。クラウド API は使いません。

## 8. ビジネスルール（1.4.x）

### 機種 include-list

- **48 モード** = `included_models.json`（include-list）。個別 UI の機種一覧の正。
- include が無い場合のみレガシー `excluded_models.json` を参照。
- **36 モード** は targets JSON のみ（include / force-all とは独立）。

### おうち割（SB 光あり）× 容量

- **スマホ**: **おうち割あり + 5GB は作らない**（実質 20GB と同系のため）。
- **iPad / AndroidTab**: パケット **1 / 5 / 50GB のみ**（20GB ティアなし）。**おうち割 + 5GB は可**。
- **TM 個別（制限解除）**: より広く 5GB + おうち等を許容し得る。
- **ケータイ**: 1GB のみ；パスに ouchi フォルダなし。スマホの機種変更では 1GB を含め得る。

### カテゴリ × 販売形態

- `iPad` / `AndroidTab` / `データ通信`: **MNP・番号移行の見積なし**（一括・個別・両エディション）。

### カテゴリ × プラン（light 系）

- light / super_light / hyper_light: 対象カテゴリは **`iPhone` と `Android` のみ**。

### 販売形態 × プラン（組合せ）

- Biz 系プラン: 機種変更可（他ルールに従う）。
- **light**: **機種変更不可**（MNP 等はルール通り）。
- **super / hyper**: **番号移行不可**；**一括** では **IRS + 割引セットのみ**。**個別**（両エディション）は **安心サポートなし + 弊社特別割引** を選べる。

### IRS・表示

- **一括** super/hyper: **IRS ありのセットのみ**（IRS なし単体は出さない）。
- **個別**（標準・TM）: 安心サポートなし等の選択可；TM は UI で XS/S 等の解除あり。
- 初期事務手数料デフォルト: `special_3000`（標準税抜 3,000 / TM 個別 **4,500** 税抜）。
- 標準初期手数料オプション: `include_standard_initial_fee`。
- super light: 標準は **50GB のみ**（TM 個別は他容量可）。
- 前払い IPS: 表示モード `lump` / `monthly_as_running`（UI で選択）。
- PDF の light 系追加割引表示: **弊社特別割引**（表示専用）。
- 新トクするサポート＋注記: **48 モードのみ**（24/36 では省略）。
- 現場向け txt: **UTF-8 BOM**；内容が `?` だけになっていたら破損 — 復元すること（エンコーディング「修正」で誤魔化さない）。

## 9. 起動時更新確認（標準のみ）

- 参照: `N:\01.ツールズ\見積もり作成ツール\latest.json`
- 約 2.5 秒タイムアウト；失敗時は **無言**
- リモート `version` が手元 `APP_VERSION` より新しいときだけ通知；Yes で ZIP がある Explorer（自動置換しない）
- 同一バージョンは当日スヌーズ
- **TM は実行しない**；リモート `edition ≠ standard` の json は無視
- **現場リリース後**: ZIP 配置と `latest.json` の `version`・`zip` を一致させる。例: `system/data/latest.example.json`
